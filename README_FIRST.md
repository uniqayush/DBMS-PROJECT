## 👨‍🏫 FOR TEACHERS - VIEW DATABASE

### Easiest Way (Recommended):

1. **Download DB Browser for SQLite**: https://sqlitebrowser.org/
2. **Install** and open it
3. Click **"Open Database"**
4. Navigate to this project → `server` folder
5. Select **`lexilearn.db`**
6. Click **"Browse Data"** tab
7. Select **"vocabulary"** from dropdown
8. **See all 1000+ words in a table!**

### Alternative - Online (No Installation):

1. Go to: https://inloop.github.io/sqlite-viewer/
2. Upload: `server/lexilearn.db`
3. View in browser

## 🚀 TO RUN THE APPLICATION

### Start Backend:
```bash

```

### Start Frontend (New Terminal):
```bash
cd my-react-app
npm run dev
```
App: http://localhost:5173
